## 三、多智能体 API 接入已知条件（依据已保存文档）

以下内容均以 `AgentArts/05-API调用图像理解工作流.html`（更新时间 2026-09-24）正文实际记载为准：

- **调试位置（平台控制台）**：登录 AgentArts 智能体平台（console.huaweicloud.com/agentarts）→ 左侧导航"开发中心 > 智能体管理"→"工作流"页签。被调用工作流须"已提交"（已部署）状态。
- **请求 URL 获取方法**：在"开发中心 > 智能体管理"工作流页签复制调用路径；接口形式为 `POST /runtimes/{runtime_name}/invocations`。凭证获取路径："托管与运行 > 智能体运行时"按 ID 搜索 → 进入基本信息页 → "访问与权限控制"处复制 URN → 在 URN 页面取 API Key。
- **鉴权（API Key 条件）**：工作流部署时入站身份认证选"API Key"；调用 Header `Authorization` 值为 `Bearer {api_key}`（Bearer 后有一个空格）。
- **重要字段名**：请求 Header 还有 `X-Invoke-Mode`（`debug`/`published`，默认 `published`，调试模式生成日志与详细执行步骤）和 `x-hw-agentarts-session-id`（必填，会话唯一标识，用户自定义字符串）。
- **前置条件**：调用 API 不支持平台赠送免费 token，需接入华为云 MaaS 付费模型并配置模型 API Key，或自行对接 OpenAI 协议第三方模型；否则返回 "Model call failed"。
- **图片输入约束**（图像理解工作流）：格式 .png/.jpg/.jpeg/.bmp/.gif，须以 URL（公网可访问，含华为云 OBS）传入；单张 ≤5 MB，总量 200 MB/24h，20 次/5min。
- `read-contract` 命令执行失败（PowerShell HtmlDecode 重载错误），未产出额外合同类文档，以上均来自成功保存的 HTML 页面，无臆造内容。
