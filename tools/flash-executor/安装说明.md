# 在同学的 Codex 中启用 Flash

这个目录复制自交接时实际启用的 Flash 0.2.0。入口是 `server.mjs`，运行源码位于 `releases/0.2.0`，`package-lock.json` 固定依赖。脚本通过标准输入输出接入 MCP。

## 安装

1. 使用 Windows PowerShell 和 Node.js 22 或更高版本。本项目实测 Node.js 24.15.0。需要截图时，电脑上装 Chrome 或 Edge 即可。
2. 进入本目录。安装锁定依赖并复制设置示例。

```powershell
npm.cmd ci --ignore-scripts
Copy-Item -LiteralPath settings.example.json -Destination settings.json
```

3. 在本机用文本编辑器打开 `settings.json`，保存为无 BOM 的 UTF-8。把 `endpoint` 改为自己的本地 OpenAI 兼容模型代理的 `/chat/completions` 地址，把 `bearer` 填为该代理的访问凭据。示例端口只是占位。Flash 只接受 `http://127.0.0.1`、`http://localhost` 或 `http://[::1]` 上的代理。
4. 编辑自己的 `%USERPROFILE%\.codex\config.toml`。把下面的路径改成解压后的 Flash 入口绝对路径，再重启 Codex 或重新打开会话。

```toml
[mcp_servers.flash_executor]
command = "node.exe"
args = ["D:/Projects/料理劫案现场/tools/flash-executor/server.mjs"]
startup_timeout_sec = 30
tool_timeout_sec = 420
```

## 检查是否可用

在 Codex 调用 `flash_execute` 时填本机项目根目录的绝对路径。先试一条不请求模型的验证命令。

```json
{
  "workspace": "D:/Projects/料理劫案现场",
  "mode": "verify",
  "commands": [{"id": "node-version", "command": "node.exe --version", "timeout_seconds": 10}]
}
```

`mode: "verify"` 运行指定的构建、测试或截图，不发起模型推理。`mode: "edit"` 需要代理支持 Chat Completions 的工具调用，并能处理 Flash 请求的 `auto/deepseek-v4.1-flash` 或 `auto/glm-5.3-flash` 模型标识。代理可将这些标识映射到你自己的模型服务。华为云 AgentArts 的工作流密钥用于运行料理项目，Flash 的 `bearer` 用于连接本机模型代理。

配置和运行记录留在各自电脑。业务项目与 Flash 的依赖按锁文件在自己的电脑安装。
